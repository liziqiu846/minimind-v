## 0. 项目总目标（不得偏离）

真正目标是：

1. 将已有 LLM 泛化理论拓展到一般 VLM；
2. 找到真正影响 VLM 泛化的理论因素；
3. 用 MiniMind-V 或类似小模型做第一步低成本验证；
4. 从理论自然导出训练算法或优化机制；
5. 最终真实提升任务数据集上的泛化性能，并具备向更大 VLM 扩展的可能。

**原则：理论决定实验；MiniMind-V 只是验证平台，不定义理论。**

## 1. 泛化对象的边界

任务书中的 VLM 泛化是广义“未见数据上的表现”，不能等同于单一的“新图像泛化”。

可能的未见性包括：

- 未见图像；
- 未见文本问题 / 指令；
- 未见图文组合；
- 未见域；
- 组合泛化等。

此前研究的“新图像条件下的文本生成泛化”是一个清晰且重要的**子问题**，可以继续作为理论落点，但不再代表全部 VLM 泛化。

---

## 2. 已经成立的第一层理论：VLM 压缩泛化界

### 2.1 基本建模

对图像条件自回归文本生成，单个统计单位可写成

\[
Z=(I,Y),\qquad Y=(y_1,\ldots,y_L),
\]

模型条件概率为

\[
p_h(Y\mid I)=\prod_{t=1}^{L}p_h(y_t\mid I,y_{<t}).
\]

若不同统计单位独立同分布，损失有界，且最终假设能够有限编码，则 Lotfi 等人的有限编码 / Occam 型压缩泛化框架可以直接应用于 VLM。

### 2.2 压缩复杂度

若模型编码长度为 \(C(h)\) bit，可使用形如

\[
\log\frac1{P(h)}\lesssim C(h)\ln2+2\ln C(h)
\]

的事前编码先验复杂度。

对损失区间长度为 \(\Delta\) 的风险，基本形式为

\[
R(h)\le \widehat R(h)
+
\Delta\sqrt{\frac{\log 1/P(h)+\log(1/\delta)}{2N}}.
\]

对于 NLL，prediction smoothing（预测平滑）可用于有界化。**预测平滑只是工具，不是项目最终目标。**

### 2.3 第一层理论的边界

该界不自动等价于：

- 强视觉语义理解；
- 细粒度图文匹配；
- 开放域 / 分布偏移泛化；
- 高质量生成；
- “模型真正使用图像”的强保证。

---

## 3. 已确认经验事实：码长与真实 VLM 性能会脱钩

阶段三 P/S 实验已经观察到：某些共享结构能够显著减少 checkpoint 描述长度、改善原压缩界，但真实视觉任务性能并未稳定改善，甚至会下降。

因此：

\[
\boxed{\text{更短的模型描述并不必然意味着更好的真实 VLM 泛化。}}
\]

这不是压缩界本身错误，而说明仅靠 checkpoint 描述长度不足以解释 VLM 泛化。

---

## 4. 当前理论总框架：从三类来源寻找 VLM 相比 LLM 真正新增的泛化因素

当前不预设某一个局部 proxy 或单一理论工具为唯一主线。阶段三先系统比较三条大方向。

### 4.1 数据侧

研究训练数据本身的多模态结构如何影响泛化，包括但不限于：

- 图文配对质量与噪声；
- 数据多样性与覆盖；
- 图文共现结构；
- 图像、文本、图文组合的层次化统计结构；
- 域变化与组合变化。

**要求：不能停留在“图像和文本都重要”这一显然事实，必须寻找定量、可预测、可验证的规律。**

### 4.2 模型 / 表示侧

研究 VLM 是否形成真正可迁移的跨模态表示，包括：

- 视觉与语言信息的融合方式；
- 模态失衡 / 模态坍塌；
- 跨模态共享表示与组合表示；
- 模型结构、共享方式与压缩方式如何改变跨模态信息利用；
- 为什么某些结构能减少码长但不改善真实性能。

### 4.3 训练侧

研究训练过程如何决定最终泛化，包括：

- 训练数据依赖；
- 信息论 / CMI；
- 优化稳定性；
- SGD 训练轨迹与局部统计；
- 采样、正则化、训练目标等。

CMI 现在属于这一方向中的**重要工具**，但不再预设为整个项目唯一主线。

### 4.4 三者的整体关系

当前工作假说是：VLM 泛化可能需要同时理解

\[
\boxed{
\text{数据结构}
\rightarrow
\text{模型/表示如何吸收跨模态信息}
\rightarrow
\text{训练过程如何形成最终模型}
\rightarrow
\text{未见数据泛化}
}
\]

但这只是总体研究框架，不是已证明定理。

## 5. 当前主问题

现阶段先回答：

\[
\boxed{\text{VLM 相比 LLM，泛化问题到底“新”在哪里？}}
\]

只有当某个方向满足下列条件，才值得进入深推导：

1. 有真正 VLM 特有的新科学内容；
2. 可能解释“码长—真实性能脱钩”；
3. 能自然导出训练算法或训练决策；
4. 能在 MiniMind-V 上低成本验证；
5. 原则上可以推广到一般 VLM。

---

## 6. CMI / 图像组数据依赖：保留，但降为训练侧候选主线

### 6.1 标准信息论工具

令训练集为 \(S\)，学习算法输出模型 \(W=A(S)\)。信息论泛化理论关注 \(I(W;S)\) 或条件互信息。

CMI 使用 supersample 和随机选择变量，衡量模型在多大程度上暴露“具体训练了哪些候选样本”。

若研究“新图像条件泛化”，可以把独立图像组定义为

\[
G_i=(I_i,\mathcal Y_i)
\]

并定义图像组 CMI：

\[
C_I=I(W;B\mid\widetilde G).
\]

标准 CMI 框架可在有界损失下控制对应总体的期望泛化误差。

**状态：标准工具成立；把样本空间实例化为图像组本身不构成新定理。**

### 6.2 重要边界

- CMI 表示训练样本身份依赖，不自动区分“有用规律”和“坏记忆”；
- 不能直接把总互信息最小化作为最终算法原则；
- token / caption 数不能无条件替代独立图像数；
- 训练过程代理必须有严格理论桥梁，不能靠命名对应。

---

## 7. SGD 信息论工具：可用，但不是已经完成的 VLM 理论

Neu 等人的 SGD 信息论理论表明，普通 SGD 泛化可通过训练轨迹上的随机梯度统计、局部扰动敏感性和最终输出扰动敏感性控制。

如果统计样本被合法定义为图像组，则原则上可以实例化这些工具。

但必须保留：

- 单个梯度差不能冒充完整证书；
- 多轮训练中参数已经依赖数据，简化替换必须重新证明；
- 正式结果含局部敏感性和最终扰动敏感性等项；
- 现有理论主要针对 SGD，AdamW 不能未经证明直接套用。

**状态：理论工具可用；VLM 特有的新结论尚未完成。**

---

## 8. 当前 gradient replacement \(D_I\) 路线：停止

曾尝试

\[
D_I=\sum_t\eta_t^2\|g_t-g_t^{ghost}\|_2^2.
\]

第一版正式审计分类：

\[
\boxed{\text{B — MEASUREMENT INFRA CONFOUNDED}}
\]

随后 crossed checkpoint-only pilot 解耦 model/probe seed 并增加 shared probes/panels 后，仍得到：

\[
\boxed{\text{DI\_MEASUREMENT\_STILL\_UNSTABLE}}
\]

因此停止当前 `CMI -> gradient replacement D_I` 代理桥。

这**不否定** CMI、图像组数据依赖、信息论泛化或未来其他训练过程量。

## 9. 本轮讨论形成但尚未升格为主线的理论内容

### 9.1 图像外层 + 文本内层分解

在适当条件独立假设下，可以考虑把图像层与同图文本层的统计波动或风险分开分析。

该类分解可以作为基础引理，但目前不能把“VLM 同时受图像和文本影响”包装成主创新。

### 9.2 图像数 / 每图文本数的资源分配

这可以作为未来可能的问题，但目前并非任务书要求或现有理论必然导出的主方向，不升格为主线。

### 9.3 反事实轨迹、Hessian 传播等

这些是可能的训练稳定性工具，但当前不继续深挖，除非后续大方向筛选证明它们正好对应核心科学问题。

---

## 10. 已否定 / 不再作为主线的路线

除非出现新的严格依据，不再重新包装以下路线：

1. token 数直接替代独立图像数；
2. 按 vision / projector / language 模块名称机械分摊复杂度；
3. 单独惩罚 \(I(W;I\mid Y)\) 并解释成删除坏视觉记忆；
4. 再设计一个有界视觉风险作为主要创新；
5. 共享参数局部梯度冲突解释 P/S 差异；
6. 只用 checkpoint 码长继续细调压缩结构；
7. 把 batch / optimizer-step 更新创新直接叫图像级依赖；
8. 为适配旧 MiniMind-V DataLoader 而改变理论对象；
9. 继续挽救当前 gradient replacement \(D_I\)。

---

## 11. MiniMind-V 的正确角色

MiniMind-V 仅用于：

1. 检验理论预测是否有经验解释力；
2. 低成本测试理论导出的训练算法；
3. 做必要机制验证；
4. 若结果稳定，再考虑更大 VLM。

其 DataLoader、sampler、batch 结构和特定 P/S 参数化都不是理论定义的一部分。

## 12. 实验启动规则

任何新的 Codex 任务或正式实验前必须满足：

1. 理论对象明确；
2. 科学问题来自当前冻结的大方向，而不是临时 proxy；
3. 实验单位与理论统计单位一致；
4. 可观测指标确实对应理论量或已证明代理；
5. ≤1 页科学设计冻结；
6. 通过 / 失败标准预注册；
7. 开发数据与最终确认数据职责分离；
8. 用户明确确认后才可写代码 / 跑实验。
