## 0. 项目总目标（不得偏离）

原始任务不是“做一个 MiniMind-V 实验”，也不是“去掉预测平滑”。真正目标是：

1. 将已有 LLM 泛化理论拓展到一般 VLM；
2. 找到真正影响 VLM 泛化的理论因素；
3. 用 MiniMind-V 或类似小模型做第一步低成本验证；
4. 从理论自然导出训练算法或优化机制；
5. 最终真实提升任务数据集上的泛化性能，并具备向更大 VLM 扩展的可能。

**原则：理论决定实验；MiniMind-V 只是验证平台，不定义理论。**

## 1. 已经成立的第一层理论：VLM 压缩泛化界

### 1.1 基本建模

对图像条件自回归文本生成，单个统计单位可写成

\[
Z=(I,Y),\qquad Y=(y_1,\ldots,y_L),
\]

模型条件概率为

\[
p_h(Y\mid I)=\prod_{t=1}^{L}p_h(y_t\mid I,y_{<t}).
\]

若不同图文统计单位独立同分布，损失有界，且最终假设能够有限编码，则 Lotfi 等人的有限编码 / Occam 型压缩泛化框架可以直接应用于 VLM。

### 1.2 压缩复杂度

若模型编码长度为 \(C(h)\) bit，则可使用形如

\[
\log\frac1{P(h)}\lesssim C(h)\ln2+2\ln C(h)
\]

的事前编码先验复杂度。

对损失区间长度为 \(\Delta\) 的风险，基本形式为

\[
R(h)\le \widehat R(h)
+
\Delta\sqrt{\frac{\log 1/P(h)+\log(1/\delta)}{2N}}.
\]

对于 NLL，原路线通过 prediction smoothing（预测平滑）使损失有界。**预测平滑只是处理 NLL 无界性的工具，不是项目最终目标。**

### 1.3 第一层理论的边界

该界严格控制的是所定义风险在目标 i.i.d. 图文总体上的泛化；它不自动等价于：

- 强视觉语义理解；
- 细粒度图文匹配；
- 开放域 / 分布偏移泛化；
- 高质量生成；
- “模型真正使用图像”的强保证。

## 2. 已确认的经验事实：码长与真实 VLM 性能会脱钩

阶段三已经观察到：某些共享参数结构能够显著减少 checkpoint 描述长度、改善原压缩界，但真实视觉任务性能并未稳定改善，甚至会下降。

因此当前项目的核心科学问题变为：

\[
\boxed{\text{为什么更短的模型描述并不必然带来更好的 VLM 真实泛化？}}
\]

这不是压缩界“错误”，而说明 **checkpoint 码长可能只是更深层训练数据依赖复杂度的粗上界 / 粗代理**。

---

## 3. 当前第二层理论主线：从“模型有多短”转向“模型依赖了哪些训练样本”

### 3.1 标准信息论视角

令训练集为 \(S\)，学习算法输出模型 \(W=A(S)\)。信息论泛化理论关注：

\[
I(W;S),
\]

即最终模型包含多少关于具体训练数据的信息。

标准结果表明：对适当的有界 / 次高斯损失，训练数据与算法输出之间的互信息或条件互信息可以控制期望泛化误差。

### 3.2 为什么不能直接把互信息解释成“坏记忆”

必须保留：

\[
I(W;S)
\]

只表示**对具体训练数据的依赖**，并不自动区分：

- 有用、可迁移的规律；
- 无用、样本特有的记忆。

因此不能把“最小化总互信息”直接当成最终 VLM 算法原则。

### 3.3 CMI（条件互信息）的关键价值

CMI 使用 supersample（超样本）和随机选择变量，衡量：

> 给定候选训练样本后，从学习算法输出中能在多大程度上识别“究竟训练了哪一个样本”。

这比完整 checkpoint 码长更直接地刻画**训练样本身份依赖**。

目前我们把它视为第二层理论的主要工具，而不是最终结论。

## 4. 当前 VLM 特有理论对象：图像组级数据依赖

### 4.1 理论统计单位

对于“新图像泛化”，当前理论优先采用的理想统计单位是一个**独立图像组**：

\[
G_i=(I_i,\mathcal Y_i),
\]

其中 \(\mathcal Y_i\) 表示该图像对应的一组合法条件文本 / 监督信号。

核心原因：多条文本可以减少**给定同一图像后的条件预测不确定性**，但它们不能凭空制造新的独立图像。

因此一般原则是：

\[
\boxed{\text{新图像泛化的外层有效样本量由独立图像来源控制。}}
\]

内部 caption / token 数量可以帮助条件学习，但不能无条件把新图像样本量从 \(N\) 变成 \(NT\) 或 \(NM\)。

### 4.2 图像组 CMI（当前候选核心量）

对 i.i.d. 图像组构造 supersample，并用选择变量 \(B\) 决定每个位置采用哪一个候选图像组。定义

\[
C_I := I(W;B\mid \widetilde G).
\]

直觉：

> \(C_I\) 衡量最终模型在多大程度上暴露“训练时具体用了哪些图像组”。

若损失有界，标准 CMI 框架可以在“图像组作为统计样本”的前提下控制对应总体的期望泛化误差。

**状态：基础工具已成立；VLM 图像组只是对标准 CMI 样本空间的实例化。不能仅凭这一点声称新定理。**

---

## 5. 当前真正可能产生新科学内容的地方

我们的目标不是重新命名标准 CMI，而是回答：

\[
\boxed{
\text{VLM 的跨模态、层次化数据结构是否能产生比普通 joint-sample CMI 更有解释力的泛化规律？}
}
\]

当前重点包括：

1. **外层独立图像 vs 内层条件文本**：两类统计信息是否以不同方式进入泛化；
2. **图像身份依赖**：是否能解释 checkpoint 码长无法解释的真实性能差异；
3. **训练过程可计算化**：能否把抽象 CMI 严格上界到训练轨迹上的可观测量；
4. **算法化**：这个可观测量是否能成为训练目标，而不是只做事后诊断。

---

## 6. CMI → SGD 训练轨迹：已确认的理论工具与边界

Neu 等人的 SGD 信息论泛化理论证明：普通 SGD 的泛化可以通过沿训练轨迹的局部随机梯度统计、局部平滑 / 扰动敏感性以及最终输出对扰动的敏感性来控制；其技术使用信息论界与虚拟扰动分析。

因此，如果“样本”被合法定义为图像组，则原则上可以把其 SGD 理论实例化到图像组数据上。

但必须保留以下边界：

- 不能把一个简单的 \(\|g_t-g_{t-1}\|^2\) 自动称为图像依赖复杂度；
- 多轮训练中 \(W_t\) 已依赖训练数据，任何简化的总体梯度方差替换都必须重新证明；
- Neu 的正式结果还含局部敏感性和最终扰动敏感性等项，单个“梯度创新”项不能冒充完整证书；
- Neu 的正式理论针对 SGD。**AdamW 的动量、二阶矩预条件和 decoupled weight decay 不能未经证明直接纳入同一定理。**

**状态：理论工具可用，但“VLM 图像组 CMI → AdamW 可计算正则”尚未完成严格证明。**

## 7. 当前尚未完成、必须继续 build 的理论任务

### T1. 图像组级正式定理

需要给出完整定义、假设、风险对象和证明：

- 图像组 \(G_i\) 的总体分布；
- 训练算法；
- 有界损失；
- 图像组 CMI；
- 泛化结论。

这一步主要是把标准 CMI 正确、无歧义地实例化到 VLM 新图像泛化对象。

### T2. 层次化“图像外层 + 条件文本内层”理论

需要判断能否得到真正比普通 joint-CMI 更强的结论，而不是仅做链式法则换记号。

任何 \(N\) 与 \(NM\) 的双尺度结论都必须重新严格证明；**当前不视为已完成定理。**

### T3. 图像组 CMI 的可计算上界

目标：

\[
C_I
\longrightarrow
\text{训练路径上可计算、可训练的量}.
\]

SGD 虚拟扰动理论是当前最可能的桥，但必须完整保留所有必要项和假设。

### T4. 从理论量导出算法

只有当可计算量满足：

- 理论上确实控制所关心的泛化项；
- 能低成本估计；
- 不只是普通梯度方差 / 普通正则的重新命名；
- 能解释码长—真实性能脱钩；

才进入新的训练算法设计。

## 8. 已否定 / 不再作为主线的路线

以下内容不得在后续被重新包装成“新主线”，除非出现新的严格理论依据：

1. **token 数直接替代独立图像数**：token 级界不能自动认证新图像泛化；
2. **按照 vision / projector / language 模块名称分别收费**：复杂度取决于数据依赖，不取决于模块名字；
3. **单独惩罚 \(I(W;I\mid Y)\) 等同于删除坏视觉记忆**：该互信息同时包含有用视觉规律；
4. **再设计一个有界视觉风险作为主创新**：阶段三已经做过接近的有界视觉风险；
5. **共享参数局部梯度冲突解释 P/S 差异**：已完成严格诊断，关键预注册标准失败；
6. **只用 checkpoint 码长继续细调压缩结构**：已不足以解释真实性能脱钩；
7. **把 batch / optimizer-step 更新创新量直接叫“图像级依赖”**：如果数据单位不是图像组，该解释不成立；
8. **为了适配 MiniMind-V 旧 DataLoader 而改变理论对象**：禁止。理论先行，实验应重新设计以满足理论。

## 9. MiniMind-V 的正确角色

MiniMind-V 仅用于：

1. 检验理论预测是否有经验解释力；
2. 低成本测试从理论导出的训练算法；
3. 做必要的机制验证和消融；
4. 若结果稳定，再考虑更大 VLM。

MiniMind-V 的：

- DataLoader；
- sampler；
- 当前 batch 结构；
- 特定 P/S 参数化；

都不是理论定义的一部分。

如果现有训练协议不满足理论统计单位，则应**重新设计实验协议**，而不是降低理论定义去迁就旧代码。

## 11. 当前最近一步的实验审计结论

原计划想在现有 P/S 训练协议中记录“图像级梯度创新”。审计发现：

- 实际 dataset index 是普通 `image + canonical conversation` pair；
- 每个 optimizer step 混合多个 pair；
- 抽样存在重复 catalog unit；
- sampler 没有按同一图像聚合其条件文本。

因此该协议只能得到 batch / step 更新创新，**不能严谨解释为图像组依赖**。

正确处理是：停止该实验，不修改理论；后续如果验证图像组理论，应设计新的、与理论统计单位一致的实验协议。

3. 是否能自然导出新的训练决策或训练算法？

若明显不能，则不作为主线提出。

## 13. 当前一句话理论主线

\[
\boxed{
\text{VLM 泛化不仅取决于模型最终有多容易描述，还可能取决于训练算法对具体图像样本身份的依赖；}
\\
\text{我们要把这种图像级数据依赖从抽象 CMI 推到可计算训练量，并最终导出可提升新图像泛化的训练算法。}
}
\]

这是当前工作假说和理论 build 的中心，但**最后一句中的“推到可计算训练量并导出算法”仍是待完成任务，不是已证明结果。**
