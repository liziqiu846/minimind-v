# LITMAP-01 Round 1 — VLM 泛化机制系统文献地图

**日期**：2026-08-07  
**阶段**：阶段三  
**类型**：预注册文献筛选与候选机制生成；不包含新模型训练  
**不可变性**：本文件提交后不修改判定标准；如需修订，创建新 round。

## 科学问题

在冻结的 Research Envelope 内，数据、表示与训练三侧的哪些跨模态机制，具有足够
文献依据与 VLM 特有性，能够成为解释“checkpoint 描述长度下降但真实 VLM
泛化未稳定改善”的可证伪候选？

## 假设

假设 H：现有可靠文献中至少存在一个机制，其核心对象是图像—文本关系的质量、
保持或优化，而不是单模态容量的重新命名；因此该机制能同时给出与码长脱钩相关的
方向性解释、最低成本反证和自然训练干预出口。

若系统筛选后没有机制同时满足这些条件，则 H 在本轮文献覆盖范围内不成立。

## VLM 特有性

候选必须依赖图像与文本之间的配对、对齐、条件利用、组合关系或跨模态优化动态。
仅适用于任意神经网络/LLM 的复杂度、稳定性或正则化结论，不因用于 VLM 而自动
获得 VLM 特有性。

## 可证伪预测

至少一个保留候选应能在不重新训练模型的最低成本测试中产生预先可写明的方向性
预测；或者，若必须训练才能合法验证，应能形成一个最小正式训练设计并进入
`REVIEW_QUEUE`。若所有候选只能事后拟合历史性能、不能产生方向性预测，则否定
本轮假设。

## 最小实验

1. 以 2026-08-07 为检索日，对数据、表示、训练三侧及相邻泛化理论执行可复现检索；
   优先 arXiv、OpenAlex、Semantic Scholar/Crossref 与顶会/期刊原始页面。
2. 纳入 2018–2026 年直接研究多模态数据、跨模态表示/利用、VLM/LVLM 训练或
   泛化的论文；更早论文仅在属于理论基础时纳入。
3. 排除只讨论工程规模、无泛化/迁移/鲁棒性含义，或不能区分 VLM 与普通 LLM
   问题的工作。
4. 对真正影响判断的论文标注
   `FORMAL_THEORY`、`EMPIRICAL_MECHANISM`、`ALGORITHMIC_EVIDENCE` 或
   `HYPOTHESIS_ONLY`，并核查对象、数据假设、模型/损失和可迁移边界。
5. 按主题综合，不按论文逐篇堆叠；最多保留 5 个候选，并逐项评估：
   VLM 特有性、脱钩解释、可证伪性、理论空间、算法出口、MiniMind-V 低成本验证。
6. 历史 P/S artifact 只用于约束候选与生成假设，不作为新候选的独立验证。

## 支持标准

至少一个候选同时满足：

1. 有两项以上相互独立的可靠文献证据，且至少一项是直接多模态实证、算法证据或
   正式理论；
2. 机制对象不是 checkpoint code length 或 held-out error 的同义改写；
3. 能解释“复杂度降低可能同时损害任务相关跨模态关系”；
4. 能写出最低成本、方向明确、可失败的验证；
5. 能自然导出数据选择、目标函数、采样、正则化或结构训练原则。

## 否定标准

满足任一项即否定相应候选；若所有候选均被否定，则否定 H：

1. VLM 特有性不足，只是通用 LLM/神经网络理论重命名；
2. 只能通过对同一历史 artifact 试多个 proxy 后挑相关性存活；
3. 不能产生独立于 held-out error 的方向性预测；
4. 文献结论依赖 CLIP 分类/检索设定且没有合法桥梁迁移到生成式 LVLM；
5. 算法出口只是“增大模型/数据”或继续优化 checkpoint 码长。

## 无法判断标准

1. 公开接口不可用或全文不足，无法核查关键定理/实验对象；
2. 文献仅支持机制存在，但没有直接连接未见数据泛化；
3. 唯一合法验证需要今晚禁止的新正式训练；
4. MiniMind-V 现有 artifact 不包含区分竞争解释所需的干预或测量。

## 可能混杂

- 将 CLIP 对比学习结果直接外推到生成式 LVLM；
- 将错配图像性能差称为互信息或正式视觉风险；
- 用同一 P/S 历史结果同时发现并“验证”候选；
- 论文标题/摘要中的“alignment”“generalization”与本项目理论对象不一致；
- 最新预印本尚未同行评审；
- 检索 API 覆盖和排序偏差。
